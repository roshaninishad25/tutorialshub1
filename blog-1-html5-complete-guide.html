📝 HTML5 Basics & Structure

Every HTML5 document starts with a proper DOCTYPE and semantic structure. The basic HTML5 template includes essential elements that provide meaning to your content and ensure proper rendering across browsers.

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Your Page Title</title> <meta name="description" content="Page description for SEO"> </head> <body> <header> <nav>Navigation</nav> </header> <main> <h1>Main Heading</h1> <p>Your content goes here</p> </main> <footer>Footer content</footer> </body> </html>

Essential Meta Tags

Meta tags provide crucial information about your webpage to browsers and search engines. The viewport meta tag ensures responsive design, while charset specifies character encoding. Description meta tags are vital for SEO, appearing in search results.

🏗️ Semantic HTML5 Elements

Semantic HTML5 elements give meaning to your content structure, making it accessible to screen readers and understandable to search engines. These elements replace generic div elements with purpose-specific tags.

Key Semantic Elements

<header>

Contains introductory content or navigation links

<nav>

Defines navigation links within your document

<main>

Specifies the main, unique content of the document

<article>

Self-contained content that could stand alone

<section>

Groups related content within a document

<aside>

Content aside from the main content (sidebar)

<footer>

Contains footer information, copyright, etc.

<figure> & <figcaption>

Self-contained content with caption

<article> <header> <h1>Article Title</h1> <time datetime="2025-01-15">January 15, 2025</time> </header> <section> <h2>Section Heading</h2> <p>Section content here...</p> <figure> <img src="image.jpg" alt="Description"> <figcaption>Image caption</figcaption> </figure> </section> <footer> <p>Article footer content</p> </footer> </article>

📋 HTML5 Forms & Input Types

HTML5 revolutionized form handling with new input types, validation attributes, and built-in browser validation. These improvements enhance user experience and reduce the need for JavaScript validation.

New Input Types

<form> <label for="email">Email:</label> <input type="email" id="email" required> <label for="url">Website:</label> <input type="url" id="url" placeholder="https://example.com"> <label for="tel">Phone:</label> <input type="tel" id="tel" pattern="[0-9]{3}-[0-9]{3}-[0-9]{4}"> <label for="date">Date:</label> <input type="date" id="date" min="2025-01-01" max="2025-12-31"> <label for="range">Volume:</label> <input type="range" id="range" min="0" max="100" value="50"> <label for="color">Color:</label> <input type="color" id="color" value="#ff6b6b"> <button type="submit">Submit</button> </form>

Form Validation Attributes

HTML5 introduces powerful validation attributes that work without JavaScript:

  • required - Field must be filled
  • pattern - Must match a regex pattern
  • min/max - Numeric or date range limits
  • minlength/maxlength - Text length constraints
  • step - Valid increments for numeric inputs

🎵 Multimedia Elements

HTML5 provides native support for audio and video content without requiring plugins like Flash. The <audio> and <video> elements make embedding media simple and accessible.

Video Element

<video width="640" height="360" controls poster="video-poster.jpg"> <source src="video.mp4" type="video/mp4"> <source src="video.webm" type="video/webm"> <track kind="subtitles" src="subtitles.vtt" srclang="en" label="English"> Your browser does not support the video tag. </video>

Audio Element

<audio controls> <source src="audio.mp3" type="audio/mpeg"> <source src="audio.ogg" type="audio/ogg"> Your browser does not support the audio element. </audio>

Key Attributes

  • controls - Shows browser default controls
  • autoplay - Starts playing automatically (use sparingly)
  • loop - Repeats when finished
  • muted - Starts with audio muted
  • poster - Image shown before video loads

🎨 Canvas API & Graphics

The HTML5 Canvas element provides a powerful drawing surface for creating dynamic graphics, animations, and visualizations. Using JavaScript, you can draw shapes, images, and complex animations directly in the browser.

<canvas id="myCanvas" width="500" height="300"></canvas> <script> const canvas = document.getElementById('myCanvas'); const ctx = canvas.getContext('2d'); // Draw rectangle ctx.fillStyle = '#ff6b6b'; ctx.fillRect(50, 50, 100, 75); // Draw circle ctx.beginPath(); ctx.arc(250, 100, 50, 0, 2 * Math.PI); ctx.fillStyle = '#4ecdc4'; ctx.fill(); // Draw text ctx.font = '24px Arial'; ctx.fillStyle = '#333'; ctx.fillText('Canvas Graphics', 150, 200); </script>

Canvas Applications

  • Interactive games and animations
  • Data visualization and charts
  • Image editing and filters
  • Real-time video processing
  • Particle effects and simulations

🖼️ SVG Graphics & Animations

Scalable Vector Graphics (SVG) provide resolution-independent graphics that scale perfectly at any size. Unlike raster images, SVG graphics are defined with XML markup and can be manipulated with CSS and JavaScript.

<svg width="200" height="200" viewBox="0 0 200 200"> <!-- Animated circle --> <circle cx="100" cy="100" r="50" fill="#4ecdc4"> <animate attributeName="r" values="50;70;50" dur="2s" repeatCount="indefinite"/> </circle> <!-- Rotating rectangle --> <rect x="75" y="75" width="50" height="50" fill="#ff6b6b" opacity="0.7"> <animateTransform attributeName="transform" type="rotate" from="0 100 100" to="360 100 100" dur="4s" repeatCount="indefinite"/> </rect> </svg>

SVG Benefits

  • Infinitely scalable without quality loss
  • Small file sizes for simple graphics
  • Searchable and indexable text
  • Styleable with CSS
  • Animatable with SMIL and JavaScript
  • Accessible with proper markup

🔍 SEO Best Practices

HTML5 provides semantic elements and attributes that significantly improve search engine optimization. Proper HTML5 structure helps search engines understand your content hierarchy and improve rankings.

SEO Optimization Tips

  • Use semantic HTML5 elements - header, nav, main, article, section, aside, footer
  • Proper heading hierarchy - Use h1 for main title, h2-h6 for subheadings
  • Descriptive meta tags - Unique title and description for each page
  • Alt text for images - Describe images for accessibility and SEO
  • Structured data - Use schema.org markup for rich snippets
  • Clean URLs - Use descriptive, keyword-rich URLs
  • Mobile optimization - Ensure responsive design and fast loading
<article itemscope itemtype="https://schema.org/Article"> <header> <h1 itemprop="headline">Article Title</h1> <time datetime="2025-01-15" itemprop="datePublished"> January 15, 2025 </time> <img src="author.jpg" alt="Author Name" itemprop="author" itemscope itemtype="https://schema.org/Person"> </header> <section itemprop="articleBody"> <p>Article content here...</p> <img src="content-image.jpg" alt="Descriptive alt text" itemprop="image"> </section> </article>
