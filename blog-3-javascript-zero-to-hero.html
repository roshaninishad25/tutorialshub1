📝 JavaScript Fundamentals

JavaScript fundamentals form the foundation of all web development. Understanding variables, data types, operators, and control structures is essential for writing clean, efficient code.

Variables and Data Types

// Modern variable declarations let userName = "John Doe"; // Can be reassigned const age = 25; // Cannot be reassigned var oldStyle = "Avoid using"; // Function scoped, avoid // Data types let str = "Hello World"; // String let num = 42; // Number let bool = true; // Boolean let nothing = null; // Null let notDefined; // Undefined let unique = Symbol("id"); // Symbol let bigInt = 123n; // BigInt // Objects and Arrays let person = { name: "Alice", age: 30, city: "New York" }; let colors = ["red", "green", "blue"];

Operators and Expressions

// Arithmetic operators let sum = 10 + 5; let product = 10 * 5; let remainder = 10 % 3; // Comparison operators console.log(10 === "10"); // false (strict equality) console.log(10 == "10"); // true (loose equality) console.log(10 !== "10"); // true // Logical operators let result = (age > 18) && (hasLicense === true); let canDrive = age >= 18 || hasPermit; // Ternary operator let message = age >= 18 ? 🔧 Functions & Scope

Functions are the building blocks of JavaScript applications. Understanding function types, scope, closures, and modern syntax is crucial for writing maintainable code.

Function Declarations and Expressions

// Function declaration function greet(name) { return `Hello, ${name}!`; } // Function expression const add = function(a, b) { return a + b; }; // Arrow function (ES6) const multiply = (a, b) => a * b; // Arrow function with multiple statements const calculateArea = (radius) => { const pi = 3.14159; return pi * radius * radius; }; // Default parameters function createButton(text = "Click me", color = "blue") { return { text, color }; } // Rest parameters function sum(...numbers) { return numbers.reduce((total, num) => total + num, 0); }

Scope and Closures

// Global scope let globalVar = "I'm global"; function outerFunction() { // Function scope let outerVar = "I'm outer"; function innerFunction() { // Inner function scope let innerVar = "I'm inner"; console.log(globalVar); // Accessible console.log(outerVar); // Accessible console.log(innerVar); // Accessible } return innerFunction; } // Closure example function createCounter() { let count = 0; return function() { count++; return count; }; } const counter = createCounter(); console.log(counter()); // 1 console.log(counter()); // 2

Higher-Order Functions

// Function that takes a function as parameter function withLogging(fn) { return function(...args) { console.log(`Calling ${fn.name} with:`, args); const result = fn(...args); console.log(`Result:`, result); return result; }; } // Function that returns a function function multiplyBy(factor) { return function(number) { return number * factor; }; } const double = multiplyBy(2); const triple = multiplyBy(3); console.log(double(5)); // 10 console.log(triple(5)); // 15

📊 Arrays & Objects

Arrays and objects are fundamental data structures in JavaScript. Mastering their methods and manipulation techniques is essential for efficient data handling.

Array Methods

const numbers = [1, 2, 3, 4, 5]; // Map: Transform each element const doubled = numbers.map(n => n * 2); // [2, 4, 6, 8, 10] // Filter: Select elements const evens = numbers.filter(n => n % 2 === 0); // [2, 4] // Reduce: Accumulate values const sum = numbers.reduce((acc, n) => acc + n, 0); // 15 // Find: Search for element const found = numbers.find(n => n > 3); // 4 // Some/Every: Test elements const hasEven = numbers.some(n => n % 2 === 0); // true const allPositive = numbers.every(n => n > 0); // true // Chaining methods const result = numbers .filter(n => n % 2 === 0) .map(n => n * 10) .reduce((acc, n) => acc + n, 0); // 60

Object Manipulation

const person = { name: "John", age: 30, city: "New York" }; // Object destructuring const { name, age } = person; // Spread operator const updatedPerson = { ...person, age: 31, country: "USA" }; // Object methods const keys = Object.keys(person); // ["name", "age", "city"] const values = Object.values(person); // ["John", 30, "New York"] const entries = Object.entries(person); // [["name", "John"], ...] // Dynamic properties const propName = "email"; const user = { [propName]: "john@example.com" }; // Computed property names const calculator = { ["add" + "Numbers"](a, b) { return a + b; } };

Advanced Array Techniques

// Flat and flatMap (ES2019) const nested = [[1, 2], [3, 4], [5, 6]]; const flattened = nested.flat(); // [1, 2, 3, 4, 5, 6] const sentences = ["Hello world", "How are you"]; const words = sentences.flatMap(sentence => sentence.split(" ")); // ["Hello", "world", "How", "are", "you"] // Array.from and Array.of const fromString = Array.from("hello"); // ["h", "e", "l", "l", "o"] const arrayOfNumbers = Array.of(1, 2, 3); // [1, 2, 3] // Sorting with custom comparator const users = [ { name: "Alice", age: 30 }, { name: "Bob", age: 25 }, { name: "Charlie", age: 35 } ]; users.sort((a, b) => a.age - b.age);

🌐 DOM Manipulation

Selecting Elements

// Modern selectors const button = document.querySelector("#submitBtn"); const buttons = document.querySelectorAll(".btn"); const firstDiv = document.querySelector("div"); // Legacy selectors (avoid) const byId = document.getElementById("myId"); const byClass = document.getElementsByClassName("myClass"); const byTag = document.getElementsByTagName("div"); // Selecting from within element const container = document.querySelector(".container"); const innerButtons = container.querySelectorAll("button");

Modifying Elements

// Changing content element.textContent = "New text content"; element.innerHTML = "Bold text"; // Changing attributes element.setAttribute("class", "new-class"); element.id = "new-id"; // Changing styles element.style.color = "red"; element.style.backgroundColor = "#f0f0f0"; // Using CSS classes element.classList.add("active"); element.classList.remove("hidden"); element.classList.toggle("visible"); element.classList.contains("highlight"); // Creating elements const newDiv = document.createElement("div"); newDiv.textContent = "New element"; newDiv.className = "box"; // Appending elements document.body.appendChild(newDiv); parentElement.insertBefore(newDiv, referenceElement); // Removing elements element.remove(); parentElement.removeChild(childElement);

Event Handling

// Event listeners button.addEventListener("click", function(event) { console.log("Button clicked!"); console.log("Event object:", event); }); // Arrow function with event button.addEventListener("click", (event) => { event.target.textContent = "Clicked!"; }); // Event delegation document.addEventListener("click", function(event) { if (event.target.classList.contains("dynamic-button")) { handleDynamicButtonClick(event); } }); // Multiple event types element.addEventListener("mouseenter", highlight); element.addEventListener("mouseleave", unhighlight); // Event options button.addEventListener("click", handleClick, { once: true, // Remove after first click passive: true, // Improve performance capture: false // Use bubbling phase }); // Custom events const customEvent = new CustomEvent("dataLoaded", { detail: { data: [1, 2, 3] } }); element.dispatchEvent(customEvent);

⏱️ Async Programming

Asynchronous programming is essential for handling operations like API calls, file operations, and timers. Master callbacks, promises, and async/await for modern JavaScript development.

Callbacks

// Basic callback function fetchData(callback) { setTimeout(() => { const data = { id: 1, name: "John" }; callback(data); }, 1000); } fetchData(function(data) { console.log("Received:", data); }); // Callback hell (avoid this) getData(function(a) { getMoreData(a, function(b) { getMoreData(b, function(c) { console.log("Final data:", c); }); }); });

Promises

// Creating promises const myPromise = new Promise((resolve, reject) => { setTimeout(() => { const success = true; if (success) { resolve("Operation successful!"); } else { reject("Operation failed!"); } }, 1000); }); // Using promises myPromise .then(result => console.log(result)) .catch(error => console.error(error)) .finally(() => console.log("Operation complete")); // Promise methods Promise.all([promise1, promise2, promise3]) .then(results => console.log("All done:", results)); Promise.race([promise1, promise2]) .then(winner => console.log("First finished:", winner)); // Chaining promises fetchUser() .then(user => fetchPosts(user.id)) .then(posts => displayPosts(posts)) .catch(error => handleError(error));

Async/Await

// Async function async function fetchUserData(userId) { try { const user = await fetch(`/api/users/${userId}`); const userData = await user.json(); const posts = await fetch(`/api/posts?userId=${userId}`); const userPosts = await posts.json(); return { user: userData, posts: userPosts }; } catch (error) { console.error("Error fetching data:", error); throw error; } } // Using async/await async function displayUserData() { try { const data = await fetchUserData(1); console.log("User data:", data); } catch (error) { console.error("Failed to load user data"); } } // Parallel async operations async function loadMultipleData() { const [users, posts, comments] = await Promise.all([ fetchUsers(), fetchPosts(), fetchComments() ]); return { users, posts, comments }; }

🚀 ES2024 Features

JavaScript continues to evolve with new features that make code more expressive and efficient. ES2024 introduces powerful additions that every modern developer should know.

Array Grouping

const people = [ { name: "Alice", age: 25, city: "NYC" }, { name: "Bob", age: 30, city: "NYC" }, { name: "Charlie", age: 25, city: "LA" } ]; // Group by age const groupedByAge = Object.groupBy(people, person => person.age); /* { 25: [{ name: "Alice", age: 25, city: "NYC" }, { name: "Charlie", age: 25, city: "LA" }], 30: [{ name: "Bob", age: 30, city: "NYC" }] } */ // Group by city const groupedByCity = Map.groupBy(people, person => person.city);

Promise.withResolvers()

// New way to create promises with external resolve/reject const { promise, resolve, reject } = Promise.withResolvers(); // Resolve or reject from outside setTimeout(() => { resolve("Success after 2 seconds!"); }, 2000); // Use the promise promise.then(console.log);

RegExp v Flag (Unicode Sets)

// Unicode set notation with v flag const emojiRegex = /^\p{Emoji}+$/v; console.log(emojiRegex.test("😀😃😄")); // true console.log(emojiRegex.test("hello")); // false // Set operations in regex const pattern = /[\p{Letter}&&\p{Script=Latin}]+/v;

Well-formed JSON.stringify()

// Properly handles unpaired surrogate code points const problematicString = "Hello\uD800World"; console.log(JSON.stringify(problematicString)); // "HelloWorld"

🎓 Advanced Concepts

Deep understanding of JavaScript's advanced concepts separates good developers from great ones. Master prototypes, inheritance patterns, memory management, and performance optimization.

Prototypes and Inheritance

// Constructor function function Animal(name) { this.name = name; } Animal.prototype.speak = function() { return `${this.name} makes a sound`; }; // Inheritance function Dog(name, breed) { Animal.call(this, name); this.breed = breed; } // Set up prototype chain Dog.prototype = Object.create(Animal.prototype); Dog.prototype.constructor = Dog; Dog.prototype.speak = function() { return `${this.name} barks`; }; // Modern class syntax (syntactic sugar) class Animal { constructor(name) { this.name = name; } speak() { return `${this.name} makes a sound`; } } class Dog extends Animal { constructor(name, breed) { super(name); this.breed = breed; } speak() { return `${this.name} barks`; } }

Closures in Practice

// Private variables with closures function createBankAccount(initialBalance) { let balance = initialBalance; return { deposit: function(amount) { balance += amount; return balance; }, withdraw: function(amount) { if (amount <= balance) { balance -= amount; return balance; } return "Insufficient funds"; }, getBalance: function() { return balance; } }; } const account = createBankAccount(1000); console.log(account.deposit(500)); // 1500 console.log(account.withdraw(200)); // 1300 console.log(account.getBalance()); // 1300

Memory Management

// Memory leaks and prevention let largeArray = new Array(1000000).fill(0); // Clear references when done largeArray = null; // WeakMap for garbage collection-friendly associations const weakMap = new WeakMap(); const obj = { id: 1 }; weakMap.set(obj, "metadata"); // When obj is garbage collected, the entry is removed too // Event listener cleanup class Component { constructor() { this.handleClick = this.handleClick.bind(this); document.addEventListener("click", this.handleClick); } destroy() { document.removeEventListener("click", this.handleClick); } }

Performance Optimization

// Debouncing function debounce(func, wait) { let timeout; return function executedFunction(...args) { const later = () => { clearTimeout(timeout); func(...args); }; clearTimeout(timeout); timeout = setTimeout(later, wait); }; } // Throttling function throttle(func, limit) { let inThrottle; return function() { const args = arguments; const context = this; if (!inThrottle) { func.apply(context, args); inThrottle = true; setTimeout(() => inThrottle = false, limit); } }; } // Memoization function memoize(func) { const cache = new Map(); return function(...args) { const key = JSON.stringify(args); if (cache.has(key)) { return cache.get(key); } const result = func.apply(this, args); cache.set(key, result); return result; }; }

✨ Best Practices & Patterns

Writing clean, maintainable JavaScript code requires following established patterns and best practices. These guidelines will help you write professional-quality code.

Code Style Guidelines

  • Use meaningful variable and function names
  • Keep functions small and focused on single responsibility
  • Use const and let instead of var
  • Prefer arrow functions for callbacks
  • Use template literals for string concatenation
  • Destructure objects and arrays when possible
  • Use ESLint for code consistency

Error Handling

// Try-catch with specific error handling try { const data = JSON.parse(jsonString); processData(data); } catch (error) { if (error instanceof SyntaxError) { console.error("Invalid JSON format"); } else { console.error("Unexpected error:", error); } } // Custom errors class ValidationError extends Error { constructor(message) { super(message); this.name = "ValidationError"; } } // Graceful degradation function initializeApp() { try { // Modern features if ("serviceWorker" in navigator) { registerServiceWorker(); } } catch (error) { console.warn("Feature not available:", error); // Fallback behavior } }

Security Best Practices

  • Never trust user input - always validate and sanitize
  • Use HTTPS for all communications
  • Avoid eval() and Function() constructor
  • Implement Content Security Policy (CSP)
  • Use secure cookie settings
  • Sanitize HTML before DOM insertion
  • Validate API responses

Testing Strategies

// Simple test function function test(description, testFn) { try { testFn(); console.log(`✅ ${description}`); } catch (error) { console.error(`❌ ${description}: ${error.message}`); } } // Example tests test("Array map doubles numbers", () => { const result = [1, 2, 3].map(x => x * 2); if (result.length !== 3) throw new Error("Wrong length"); if (result[0] !== 2) throw new Error("First element wrong"); }); test("Object spread creates copy", () => { const original = { a: 1, b: 2 }; const copy = { ...original }; copy.a = 3; if (original.a !== 1) throw new Error("Original modified"); });
