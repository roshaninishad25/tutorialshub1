🎯 Advanced CSS Selectors

CSS3 introduces powerful selectors that give you precise control over styling. Understanding these selectors is crucial for writing efficient, maintainable CSS without excessive classes.

Essential CSS3 Selectors

/* Attribute Selectors */ input[type="text"] { border: 1px solid #ccc; } a[href^="https"] { color: green; } img[src$=".png"] { border: 1px solid blue; } div[class*="nav"] { background: #f0f0f0; } /* Structural Pseudo-classes */ :first-child { margin-top: 0; } :last-child { margin-bottom: 0; } :nth-child(odd) { background: #f9f9f9; } :nth-of-type(2n) { color: blue; } /* UI State Pseudo-classes */ :focus { outline: 2px solid blue; } :hover { transform: scale(1.05); } :disabled { opacity: 0.5; } :checked + label { font-weight: bold; } /* Combinators */ .parent > .child { color: red; } .sibling + .adjacent { margin-top: 0; } .element ~ .following { border-left: 1px solid; }

Selector Specificity

Understanding specificity is key to debugging CSS issues. The hierarchy is: Inline styles (1000) > IDs (100) > Classes/Attributes/Pseudo-classes (10) > Elements/Pseudo-elements (1).

📦 Flexbox Complete Guide

Flexbox is a one-dimensional layout method that makes it easy to design flexible and responsive layout structures. It's perfect for arranging items in rows or columns with powerful alignment and distribution capabilities.

Flex Container Properties

.flex-container { display: flex; flex-direction: row; /* row | row-reverse | column | column-reverse */ flex-wrap: nowrap; /* nowrap | wrap | wrap-reverse */ justify-content: flex-start; /* flex-start | flex-end | center | space-between | space-around | space-evenly */ align-items: stretch; /* stretch | flex-start | flex-end | center | baseline */ align-content: stretch; /* stretch | flex-start | flex-end | center | space-between | space-around */ gap: 20px; /* Modern spacing */ }

Flex Item Properties

.flex-item { flex-grow: 0; /* How much item grows */ flex-shrink: 1; /* How much item shrinks */ flex-basis: auto; /* Base size */ flex: 1 1 auto; /* Shorthand: grow shrink basis */ align-self: auto; /* Override container align-items */ order: 0; /* Visual order */ }

  • Center content: display: flex; justify-content: center; align-items: center;
  • Equal height columns: display: flex on parent
  • Navigation bar: justify-content: space-between
  • Card layout: flex-wrap: wrap with flex items

🔲 CSS Grid Layout

CSS Grid is a two-dimensional layout system that revolutionizes web design. It enables complex layouts that were previously impossible or extremely difficult with CSS alone.

Grid Container Setup

.grid-container { display: grid; grid-template-columns: 1fr 2fr 1fr; /* Fractional units */ grid-template-rows: auto 1fr auto; /* Row heights */ grid-template-areas: "header header header" "sidebar main aside" "footer footer footer"; gap: 20px; padding: 20px; }

Grid Item Placement

.header { grid-area: header; } .sidebar { grid-area: sidebar; } .main { grid-area: main; } .aside { grid-area: aside; } .footer { grid-area: footer; } /* Alternative placement */ .featured { grid-column: 1 / 3; /* Start at line 1, end at line 3 */ grid-row: 2 / 4; /* Start at line 2, end at line 4 */ }

Advanced Grid Features

  • Auto-fit and auto-fill: Responsive grid columns
  • Minmax function: Flexible sizing constraints
  • Subgrid: Nested grid alignment
  • Grid lines: Named and numbered lines
  • Dense packing: Fill available space efficiently
.responsive-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); gap: 20px; }

🎬 CSS Animations & Transitions

CSS animations and transitions bring your websites to life with smooth, performant motion effects. Understanding the difference and when to use each is crucial for creating engaging user interfaces.

Transitions

.button { background: #007bff; color: white; padding: 12px 24px; border: none; border-radius: 4px; transition: all 0.3s ease; } .button:hover { background: #0056b3; transform: translateY(-2px); box-shadow: 0 4px 8px rgba(0,0,0,0.2); }

Keyframe Animations

@keyframes slideIn { 0% { opacity: 0; transform: translateX(-100%); } 100% { opacity: 1; transform: translateX(0); } } .animated-element { animation: slideIn 0.5s ease-out; animation-fill-mode: both; } /* Complex animation */ @keyframes pulse { 0%, 100% { transform: scale(1); } 50% { transform: scale(1.1); } } .heartbeat { animation: pulse 1s infinite; }

Performance Tips

  • Use transform and opacity for better performance
  • Avoid animating layout properties (width, height, margin)
  • Use will-change for complex animations
  • Prefer CSS animations over JavaScript when possible
  • Use reduced motion preferences for accessibility

🎨 CSS Custom Properties

CSS custom properties (variables) enable dynamic styling and theme management. They make your CSS more maintainable, reusable, and powerful.

Defining and Using Variables

:root { --primary-color: #007bff; --secondary-color: #6c757d; --success-color: #28a745; --font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; --border-radius: 4px; --transition: all 0.3s ease; } .button { background: var(--primary-color); border-radius: var(--border-radius); transition: var(--transition); } .card { border: 1px solid var(--secondary-color); border-radius: var(--border-radius); }

Dynamic Variables with JavaScript

/* CSS */ .theme-dark { --bg-color: #1a1a1a; --text-color: #ffffff; } .theme-light { --bg-color: #ffffff; --text-color: #000000; } body { background: var(--bg-color); color: var(--text-color); transition: background 0.3s ease; }
// JavaScript document.documentElement.style.setProperty('--primary-color', '#ff6b6b'); document.body.classList.toggle('theme-dark');

Advanced Use Cases

  • Theme switching (dark/light mode)
  • Responsive design breakpoints
  • Component-based styling
  • Mathematical calculations with calc()
  • Dynamic spacing systems

📱 Responsive Design Techniques

Responsive design ensures your websites work perfectly on all devices. Modern CSS provides multiple approaches to create flexible, adaptive layouts.

Media Queries

/* Mobile-first approach */ .container { padding: 10px; } @media (min-width: 768px) { .container { padding: 20px; display: flex; gap: 20px; } } @media (min-width: 1024px) { .container { max-width: 1200px; margin: 0 auto; padding: 40px; } } /* Target specific features */ @media (hover: hover) { .button:hover { transform: scale(1.05); } } @media (prefers-reduced-motion: reduce) { * { animation-duration: 0.01ms !important; animation-iteration-count: 1 !important; } }

Modern Responsive Units

.responsive-text { font-size: clamp(1rem, 2.5vw, 2rem); line-height: 1.5; } .responsive-spacing { padding: clamp(1rem, 5vw, 3rem); margin: clamp(0.5rem, 2.5vw, 1.5rem); } .responsive-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(min(300px, 100%), 1fr)); gap: clamp(1rem, 3vw, 2rem); }

Container Queries (Latest)

@container (min-width: 400px) { .card { display: flex; align-items: center; } } @container (min-width: 600px) { .card { grid-template-columns: 1fr 2fr; } }

✨ Modern Glassmorphism

Glassmorphism is a modern design trend featuring translucent elements with blur effects. Create stunning, contemporary interfaces using CSS backdrop-filter and modern properties.

Basic Glassmorphism

.glass-card { background: rgba(255, 255, 255, 0.1); backdrop-filter: blur(10px); -webkit-backdrop-filter: blur(10px); border: 1px solid rgba(255, 255, 255, 0.2); border-radius: 15px; padding: 30px; box-shadow: 0 8px 32px rgba(0, 0, 0, 0.1); } /* Dark theme glassmorphism */ .glass-dark { background: rgba(0, 0, 0, 0.3); backdrop-filter: blur(20px); border: 1px solid rgba(255, 255, 255, 0.1); }

✨ Glassmorphism Effect

This is an example of glassmorphism styling with backdrop blur, transparency, and subtle borders. Perfect for modern UI designs!

Advanced Glassmorphism Techniques

.glass-button { background: linear-gradient(135deg, rgba(255,255,255,0.1), rgba(255,255,255,0)); backdrop-filter: blur(20px); border: 1px solid rgba(255,255,255,0.18); border-radius: 50px; padding: 12px 30px; color: white; font-weight: 600; transition: all 0.3s ease; cursor: pointer; } .glass-button:hover { background: linear-gradient(135deg, rgba(255,255,255,0.2), rgba(255,255,255,0.1)); transform: translateY(-2px); box-shadow: 0 10px 40px rgba(0,0,0,0.2); } /* Animated glassmorphism */ @keyframes glassFloat { 0%, 100% { transform: translateY(0px); } 50% { transform: translateY(-10px); } } .floating-glass { animation: glassFloat 3s ease-in-out infinite; }

Browser Compatibility

Always include fallbacks for browsers that don't support backdrop-filter:

.glass { background: rgba(255, 255, 255, 0.9); /* Fallback */ background: rgba(255, 255, 255, 0.1); backdrop-filter: blur(10px); -webkit-backdrop-filter: blur(10px); } @supports not (backdrop-filter: blur(10px)) { .glass { background: rgba(255, 255, 255, 0.9); } }

⚡ CSS Performance Optimization

Optimizing CSS is crucial for fast-loading websites. Learn techniques to reduce file size, improve rendering performance, and create efficient stylesheets.

CSS Optimization Techniques

  • Minimize and compress CSS files
  • Use efficient selectors - Avoid deeply nested selectors
  • Leverage browser caching with proper headers
  • Critical CSS inlining for above-the-fold content
  • Remove unused CSS with tools like PurgeCSS
  • Use modern layout methods (Flexbox, Grid)
  • Optimize animations with transform and opacity

Critical CSS Example

/* Critical CSS - Inline in HTML */ .critical-above-fold { /* Only essential styles for initial viewport */ font-family: var(--font-family); line-height: 1.6; color: var(--text-color); } .hero { display: flex; align-items: center; justify-content: center; min-height: 100vh; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); }
